## P1 · 封面
- **作品名**：行前一刻
- **赛道**：AI+生活 · 智慧出行
- **一句话**：出门前 30 秒，生成「唯一推荐行动」；延误时自动改线
- **用户**：通勤 / 跨城办事的上班族

---

## P2 · 问题
- **谁**：海淀→中关村/国贸的通勤上班族
- **场景**：出门前在天气、地铁、网约车、日历间来回切换
- **代价**：选项越多决策越慢；延误时没有人替你改线 → 迟到、焦虑、会议开不好
- **现有不够**：高德/地铁 App 擅长「列路线」，ChatGPT 擅长「聊天」，都缺少约束下的**唯一行动 + 异常闭环**

---

## P3 · 方案（Agent 一图）
```
约束输入（起终点 / 到达时间 / 方式偏好）
        ↓
 weather_lookup  →  感知天气与缓冲建议
        ↓
 route_options   →  枚举地铁/公交/骑行/打车/混合
        ↓
 leave_time_planner → 倒推出门时刻（唯一行动）
        ↓
 [延误] replan_on_disruption → 自动改线
```
输出：**出门时刻 + 模式链 + 为什么 + 备选**

---

## P4 · 演示关键帧（三剧本）
1. **晴天通勤**：家→中关村 9:30 → 推荐骑行/地铁 + 出门时刻
2. **突发延误 +15**：触发改线 → 地铁主干 + 末端打车
3. **改目的地国贸**：重规划 10:00 前到达方案

评委 60 秒路径：打开 `/studio` → 点预设 → 看工具轨迹 → 点「突发延误」

# 行前一刻 · Demo 剧本

## A. 90 秒备用视频脚本（无网保命）

| 秒 | 画面 | 旁白 |
|---|---|---|
| 0–8 | Logo + 一句话 | 「出门前 30 秒，行前一刻给你唯一推荐行动。」 |
| 8–20 | 首页 → 进入工作室 | 「赛道 AI+生活，智慧出行。用户是通勤上班族。」 |
| 20–45 | 点「晴天通勤」预设，工具轨迹滚动 | 「Agent 依次调用天气、路线、出门时刻规划。」 |
| 45–65 | 结果卡：出门时刻 + 模式链 | 「不是十个选项，是告诉你几点出门、怎么走、为什么。」 |
| 65–85 | 点「突发延误 +15」，改线 | 「路上延误？自动改线，抢回到达时间。」 |
| 85–90 | 收束 + 仓库/体验 | 「行前一刻——决策，而不是信息堆砌。」 |

录制建议：1080p，浏览器全屏 `/studio`，语速偏慢，关键数字特写。

## B. 现场 4 分钟路演节奏

| 时间 | 内容 |
|---|---|
| 0:00–0:40 | 讲一个真人故事：开会迟到是因为「选项太多、改线太晚」 |
| 0:40–2:40 | **现场实操**：预设① → 展示工具轨迹 → 结果卡 → 预设延误改线 |
| 2:40–3:30 | 为什么是 Agent：四工具、可解释、唯一行动 vs 地图 App |
| 3:30–3:50 | 价值与 30 天验证；邀请评委扫码 |
| Q&A | 数据从哪来 / 失败怎么办 / 商业化（见下） |

### Q&A 三答
1. **数据**：Demo 用高保真北京 Mock 保证离线可演；可接天气/地图 API 与日历。
2. **失败**：工具失败降级到备选路线；现场有 90 秒录像双保险。
3. **商业化**：个人订阅「到达保障提醒」+ 园区/班车 B 端试点。
